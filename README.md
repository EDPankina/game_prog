# Space Debris Cleaner

**Space Debris Cleaner** — это прототип игры на Unity на космическую тематику.  
Игрок управляет кораблём-уборщиком на орбите и очищает пространство от космического мусора.

## Описание проекта

Игрок управляет специализированным кораблём, который перемещается в космическом пространстве, захватывает обломки мусора с помощью Tractor Beam и доставляет их на станцию утилизации. За каждый утилизированный объект игрок получает очки.


## Реализованные механики

- Управление кораблём с использованием `Rigidbody`
- Процедурная генерация космического мусора вокруг игрока
- Захват мусора с помощью Tractor Beam
- Визуализация луча через `LineRenderer`
- Физическое перемещение объектов с использованием компонентов Unity
- Станция утилизации на основе `Trigger Collider`
- Система начисления очков
- UI с названием проекта, счётом и подсказками управления

## Управление

| Клавиша | Действие |
|---|---|
| W / S | Движение вперёд / назад |
| A / D | Движение влево / вправо |
| Q / E | Поворот корабля |
| Space | Захват мусора с помощью Tractor Beam |

## Использованные инструменты Unity

- Unity 2022.3 LTS
- Rigidbody
- Colliders
- Trigger Collider
- LineRenderer
- TextMeshPro
- Prefabs
- Materials
- Camera Follow Script
